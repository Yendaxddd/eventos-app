# Pending Powers

Place power submission JSON files here for GM review.

## File Naming
`{character_name}_{power_slot}.json` - e.g., `seth_power1.json`

## Required Fields
See `templates/power_template.json` for the full schema.

## Review Process
1. User submits power via `/submitpower` command
2. JSON file created in this folder
3. GM reviews with `/reviewpower`
4. GM approves/adjusts with `/approvepower`
5. File moved to `approved/` and power becomes active
